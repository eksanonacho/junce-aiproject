## 二、核心模块说明

### 2.1 问卷模块
- 展示问卷题目（分组展示）
- 收集客户答案
- 校验必填项
- 提交后触发规则引擎

### 2.2 规则引擎（核心）
- 加载九维/四维诊断规则
- 逐维逐项匹配客户答案
- 每个检查项输出：正常 / 轻微风险 / 中风险 / 高风险
- 总体风险等级计算
- 标记需人工复核的项
- 输出结构化诊断结果

### 2.3 报告生成模块
- 接收规则引擎输出
- 按报告模板拼装内容
- 生成 HTML 版报告（手机端优先）
- PDF 导出（服务端渲染）

### 2.4 服务推荐模块
- 根据诊断结果匹配服务推荐映射表
- 区分强推荐 / 一般推荐
- 不显示价格

### 2.5 人工复核模块
- 后台查看报告列表（按风险等级筛选）
- 查看报告详情
- 复核：通过 / 驳回 / 修改报告内容
- 修改留痕（记录谁改了什么）

### 2.6 安全模块
- 客户侧：手机号短信验证
- 内部后台：JWT 认证 + RBAC 权限
- 禁用词过滤：规则引擎输出经过禁用词检查
- 免责声明：每份报告强制附加

## 三、请求链路示例（以"客户提交问卷 → 生成报告"为例）

```
1. 客户在手机端填写问卷，点"提交"
2. POST /submissions → Controller → Service
3. Service 保存提交记录 → 调用规则引擎
4. 规则引擎：
   a. 加载诊断规则（缓存在内存）
   b. 逐维逐项匹配答案
   c. 计算风险等级
   d. 输出结构化结果
5. 报告生成 Service：
   a. 接收诊断结果
   b. 拼装报告 HTML
   c. 附加免责声明
   d. 保存到 reports 表
6. 服务推荐 Service：
   a. 匹配推荐映射表
   b. 附加到报告
7. 返回报告 ID → 前端跳转报告页
8. 客户查看报告（需手机号验证）
```

## 四、认证与权限

| 用户类型 | 认证方式 | 权限范围 |
|---|---|---|
| 客户 | 手机号 + 短信验证码 | 填写问卷、查看自己的报告 |
| 内部员工 | JWT（用户名+密码） | 后台管理：查看报告、复核、导出 |
| 管理员 | JWT（管理员角色） | 全部权限 |
