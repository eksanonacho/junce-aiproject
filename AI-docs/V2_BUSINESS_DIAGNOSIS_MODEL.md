## 1. V2 产品定位

V2 系统不再只是「AI 财税问卷」，而是：

**君册企业经营初诊系统**

核心组成：

```
手机号入口 → 选择初诊模式 → 上传资料 → 补充经营问卷 → 九维规则判断 → 四维经营看板 → 人工复核 → 服务转化
```

## 2. 四维经营看板定义

### 2.1 四维

| 维度代码 | 维度名称 | 含义 |
|---------|---------|------|
| PROFIT | 利润 | 收入变化、毛利水平、费用增长、客户产品贡献 |
| RISK | 风险 | 税务申报、发票资金、社保工商合规 |
| CASH_FLOW | 现金流 | 应收回款、存货积压、应付账期、资金紧张程度 |
| EFFICIENCY | 效率 | 人效、资产利用、客户集中度、流程效率 |

### 2.2 评分标准

评分范围 **1.0 – 5.0**：

| 分数 | 标签 |
|------|------|
| 4.0 – 5.0 | 经营状态较好 |
| 3.0 – 3.9 | 经营总体一般 |
| 2.0 – 2.9 | 需重点关注 |
| 1.0 – 1.9 | 经营压力较大 |

### 2.3 综合健康度公式

```
综合 = 利润 × 0.25 + 风险 × 0.35 + 现金流 × 0.25 + 效率 × 0.15
```

风险权重最高（0.35），因为财税合规是君册核心价值。

## 3. 九维规则定义

### 3.1 九维清单

| 代码 | 名称 | 支撑四维 |
|------|------|---------|
| REVENUE_MARGIN | 收入与毛利维 | 利润 |
| COST_EXPENSE | 成本费用维 | 利润 |
| CUSTOMER_PRODUCT | 客户产品贡献维 | 利润 / 效率 |
| TAX_DECLARATION | 税务申报维 | 风险 |
| INVOICE_FUND | 发票资金维 | 风险 |
| SOCIAL_BUSINESS | 社保工商维 | 风险 |
| RECEIVABLE_COLLECTION | 应收回款维 | 现金流 |
| INVENTORY_PAYABLE | 存货付款维 | 现金流 |
| HUMAN_ASSET_EFFICIENCY | 人效资产维 | 效率 |

### 3.2 九维与四维映射

```
利润   ← REVENUE_MARGIN + COST_EXPENSE + CUSTOMER_PRODUCT
风险   ← TAX_DECLARATION + INVOICE_FUND + SOCIAL_BUSINESS
现金流 ← RECEIVABLE_COLLECTION + INVENTORY_PAYABLE
效率   ← CUSTOMER_PRODUCT + HUMAN_ASSET_EFFICIENCY
```

## 5. 资料完整度评分

```
completenessScore = (已传必传数 / 总必传数) × 70 + (已传可选数 / 总可选数) × 30
维度可信度 = 该维关联资料已上传比例 × 100
```

---

## 6. 四维评分计算

每维基础分 4.0，通过规则命中和资料缺失扣分：

```
score = max(1.0, min(5.0, 4.0 - HIGH×1.5 - MEDIUM×0.8 - docPenalty + positiveBonus))
```

`docPenalty` = 0.3 – 0.8（该维关键资料缺失越多扣越多）

**综合** = 利润 × 0.25 + 风险 × 0.35 + 现金流 × 0.25 + 效率 × 0.15

## 9. 合规边界

**统一免责文案**：
> 本系统生成内容仅作为企业经营与财税风险初步筛查参考，基于当前填写和上传资料计算，不构成最终税务、法律、审计或行政结论。具体事项建议结合完整资料由君册专业人员进一步复核。

**禁止表述**：违法了、必须补税、一定会被罚、保证解决、保证合规、100%避免风险、可以避税、税局不会查、肯定能注销成功。

**允许表述**：可能存在合规风险、建议进一步核查、建议由专业人员复核、根据目前信息暂未发现明显高风险项。
