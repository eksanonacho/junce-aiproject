## 前端开发总原则

1. **不改后端**。接口、字段、枚举以 API_CONTRACT.md 为准。
2. **不碰数据库**。所有数据通过接口读写。
3. **不发明接口字段**。请求参数和返回字段严格按 API_CONTRACT 来。
4. **枚举值一字不差**。风险等级、报告状态等枚举值和后端保持一致。
5. **BASE_URL 集中配置**。一个变量控制，方便切换本机/联调/上线地址。
6. **客户侧无需登录**。手机号验证即可查看报告。
7. **内部后台 JWT 认证**。token 自动带 Authorization，401 跳登录。
8. **手机优先**：客户侧页面优先适配手机端（375px 基准），PC 端兼容。
9. **报错先贴完整原文再分析**。

## 关键业务规则（前端必须知道）

| 规则 | 说明 |
|------|------|
| **客户无需登录** | 填写问卷不需要登录，查看报告需要手机号验证 |
| **内部后台需登录** | JWT 认证，token 过期跳登录页 |
| **高风险报告** | 客户侧可能不直接显示（待人工复核规则确认） |
| **不显示价格** | 服务推荐不显示具体价格，显示"联系君册了解详情" |
| **免责声明** | 每份报告必须展示免责声明 |
| **禁用词** | 前端不需要处理（后端已过滤），但展示时注意排版 |
