> 项目总览 / 入口文档。无论你是第一次接触本项目的开发者、接手维护的工程师、还是 AI agent，读这个文件就能快速掌握 AI 初诊项目的全貌。

---

## 一、项目是什么

**君册财税 AI 初诊网站**（对外获客工具）：潜在客户通过手机/电脑访问网站，填写初诊问卷 → 系统按君册的财税诊断规则自动分析 → 生成初诊报告 → 推荐对应服务 → 商务跟进转化。

**与小程序的关系**：
- 小程序是**内部管理工具**（OA + CRM + 任务流转），给君册员工用
- AI 初诊网站是**对外获客工具**，给潜在客户用
- 两个项目独立开发、独立部署，共用一台服务器（容器隔离）
- 预留数据打通接口（AI 初诊收集的客户可导入小程序客户档案）

**终端**：响应式 H5 网站（手机 + PC 均可访问）。

**当前阶段**：V2 企业经营初诊系统 — 全量重构已完成。后端 22 API / 18 模型 / 8 枚举，前端 9 路由 / 7 组件。分支 `feature/v2-business-diagnosis`。

## 三、项目硬边界（不可违反）

1. **AI 不替代专业判断**：AI 初诊只做"初筛"，不做"终判"。最终结论必须人工复核。
2. **不承诺结果**：AI 不能说"保证解决""一定没问题""税局不会查"。
3. **不做自动报价**：服务推荐不显示具体价格，由商务跟进时报价。
4. **不做复杂 AI Agent**：第一版是"问卷 + 规则匹配 + 报告生成"，不做多轮对话、自动追问。
5. **不编造规则**：九维/四维、风险标准、FAQ 等必须由纪姐提供，不替客户编。
6. **不等小程序**：AI 初诊独立开发，不依赖小程序发版节奏。
7. **不做第二期自动核算**：佣金/利润自动反推、复杂看板等属于二期。
