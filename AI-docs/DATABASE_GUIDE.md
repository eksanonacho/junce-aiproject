## 预计数据表（开发启动后创建）

### 预计表清单

| 表名 | 用途 | 状态 |
|------|------|------|
| `diagnosis_questionnaires` | 问卷模板：题目、选项、分组、必填标记 | ⬜ 等资料 |
| `diagnosis_submissions` | 客户提交记录：答案、提交时间、来源 | ⬜ 等资料 |
| `diagnosis_rules` | 诊断规则配置：九维/四维、检查项、判断标准 | ⬜ 等资料 |
| `risk_scenarios` | 风险场景库：场景名称、识别条件、风险等级、建议话术 | ⬜ 等资料 |
| `diagnosis_reports` | 初诊报告：风险等级、各维度结果、问题清单、建议、推荐服务 | ⬜ 等资料 |
| `service_recommendations` | 服务推荐映射：诊断情况→推荐服务→推荐等级 | ⬜ 等资料 |
| `faq_entries` | FAQ 库：问题、标准回答、是否可 AI 直接回答 | ⬜ 等资料 |
| `review_records` | 人工复核记录：报告ID、复核人、修改内容、复核结果 | ⬜ 开发后 |
| `prohibited_phrases` | 禁用话术库：禁止表述、安全替代表述 | ⬜ 等资料 |
| `leads` | 客户留资：手机号、姓名、公司名、来源、跟进状态 | ⬜ 开发后 |

### 预计枚举类型

| 枚举 | 用途 | 可选值（待纪姐确认） |
|------|------|------|
| RiskLevel | 风险等级 | 低风险 / 中风险 / 高风险 / 待人工复核 |
| ReportStatus | 报告状态 | 未复核 / 已复核 / 已驳回 / 已发布 |
| RecommendLevel | 推荐等级 | 强推荐 / 一般推荐 / 建议了解 |
| SubmissionSource | 提交来源 | 客户自助 / 员工代填 / 小程序导入 |

## 继承自小程序的规范

> 来源：小程序 DATABASE_GUIDE.md、CLAUDE.md

1. **金额字段统一 `@db.Decimal(12,2)`** — AI 初诊如有金额展示，遵守此规范
2. **枚举用数据库原生 Enum** — 从根上杜绝脏数据
3. **外键约束** — 删除时 RESTRICT，防止孤儿数据
4. **时间字段** — createdAt / updatedAt 为每表标配
5. **Prisma migration 管理** — 改结构一律走 migration，不手写 SQL
