## Case A：低风险健康企业 🟢

### 企业背景
- 公司：XX科技有限公司，注册 5 年，一般纳税人
- 员工：20 人，全员缴纳社保
- 经营：年收入稳定增长，毛利 25%+，申报正常，回款及时

### 演示操作

**Step 1 — 开始初诊**
```
/diagnosis/start → 输入手机号 13800001111 → 选择"标准初诊" → 开始初诊
```

**Step 2 — 上传资料**
```
上传以下文件（可用空白PDF占位）：
- 营业执照 (BUSINESS_LICENSE)
- 利润表 (INCOME_STATEMENT)
- 资产负债表 (BALANCE_SHEET)
- 增值税申报表 (VAT_DECLARATION)
- 银行流水 (BANK_STATEMENT)
- 工资社保个税资料 (PAYROLL_SOCIAL_SECURITY)
→ 资料完整度约 60%
```

**Step 3 — 填写问卷（关键答案）**
| 问题 | 答案 |
|------|------|
| 近一年营业收入变化情况？ | 增长超过20% |
| 主要产品或服务毛利水平如何？ | 毛利30%以上 |
| 是否存在低毛利或亏损产品？ | 否 |
| 目前是否按期进行纳税申报？ | 是 |
| 是否长期零申报？ | 否 |
| 是否有员工？ | 10-50人 |
| 社保是否正常缴纳？ | 全员正常缴纳 |
| 客户回款是否及时？ | 及时 |
| 是否存在逾期90天以上应收账款？ | 否 |
| 人员配置是否与业务量匹配？ | 匹配 |

其余问题按"正常/无问题"方向回答。

**Step 4 — 提交并查看结果**

### 预期诊断结果

| 指标 | 值 |
|------|-----|
| 综合健康度 | 4.0 - 4.5 |
| 利润评分 | 4.0 - 4.5 |
| 风险评分 | 4.0 - 4.8 |
| 现金流评分 | 3.5 - 4.2 |
| 效率评分 | 3.8 - 4.3 |
| 资料完整度 | ~60% |
| overallRiskLevel | LOW |
| customerVisible | true（AUTO_RELEASED） |
| 命中规则 | 0-2 条 LOW/MEDIUM |

### 客户侧体验
- 提交成功页：显示"标准初诊"、资料完整度 60%
- 报告页：完整四维看板可见、TOP3 行动建议、服务建议
- 雷达图：五个维度接近满分

## Case B：中风险需关注企业 🟡

### 企业背景
- 公司：XX贸易有限公司，注册 3 年，小规模纳税人
- 员工：6 人，部分缴纳社保
- 经营：收入基本持平，毛利 10-15%，偶尔逾期申报，回款经常拖延

### 演示操作

**Step 1 — 开始初诊**
```
/diagnosis/start → 输入手机号 13800002222 → 选择"标准初诊" → 开始初诊
```

**Step 2 — 上传资料**
```
上传以下文件：
- 营业执照 (BUSINESS_LICENSE)
- 利润表 (INCOME_STATEMENT)
- 资产负债表 (BALANCE_SHEET)
- 增值税申报表 (VAT_DECLARATION)
→ 资料完整度约 40%
```

**Step 3 — 填写问卷（关键答案）**
| 问题 | 答案 |
|------|------|
| 近一年营业收入变化情况？ | 基本持平 |
| 主要产品或服务毛利水平如何？ | 毛利10%-15% |
| 目前是否按期进行纳税申报？ | 是 |
| 是否长期零申报？ | 否 |
| 发票与实际业务是否匹配？ | 部分不匹配 |
| 是否有员工？ | 5-10人 |
| 社保是否正常缴纳？ | 部分缴纳 |
| 工资、个税和社保人数是否一致？ | 存在差异 |
| 客户回款是否及时？ | 经常拖延 |
| 是否存在逾期90天以上应收账款？ | 是 |

**Step 4 — 提交并查看结果**

### 预期诊断结果

| 指标 | 值 |
|------|-----|
| 综合健康度 | 2.5 - 3.2 |
| 利润评分 | 2.5 - 3.0 |
| 风险评分 | 2.5 - 3.2 |
| 现金流评分 | 2.0 - 2.8 |
| 效率评分 | 2.8 - 3.5 |
| 资料完整度 | ~40% |
| overallRiskLevel | MEDIUM（或 3+ MEDIUM 触发 HIGH） |
| customerVisible | false（NEED_REVIEW） |
| 命中规则 | 4-6 条 MEDIUM |

### 客户侧体验
- 提交成功页：显示"标准初诊"、资料完整度 40%、**"报告正由君册专业人员复核"**
- 报告页：显示 ⏳ "报告待复核" — **看不到四维看板**
- 只有后台 APPROVE 后才能查看完整报告

### 后台操作
```
/admin/login → 用户名 admin / 密码 Admin@123456
/admin/submissions → 找到该提交 → 查看报告详情
→ 查看"四维看板"标签页（后台始终可见）
→ 查看"九维规则"标签页 → 确认命中规则
→ 复核操作 → APPROVE → 添加复核意见
→ 客户侧刷新报告 → 完整看板可见
```
